# Support

DevMate is maintained by one person in their spare time. There is no paid support and no guaranteed response time.

## Where to ask

- **Something does not work**: open a [bug report](https://github.com/Kukutx/DevMate/issues/new?template=bug_report.yml). Run `devmate doctor` (or **DevMate: Doctor** in VS Code) first and include its output with private paths and addresses removed.
- **An idea or a missing capability**: open a [feature request](https://github.com/Kukutx/DevMate/issues/new?template=feature_request.yml).
- **A security problem**: do not open a public issue. Follow [SECURITY.md](SECURITY.md).

Before reporting, the troubleshooting table in the [README](README.md#troubleshooting) covers the errors people meet most often.

## Supported versions

Only the latest 4.x release is supported. DevMate 3.x is not maintained, and 4.x does not read 3.x state or configuration.

## Supported environments

| Environment | State |
|---|---|
| Windows 10/11, Node.js 24 | Developed and tested here |
| Linux (Ubuntu 24.04), Node.js 24 | Full test suite passes |
| macOS | Tested in CI only; nobody has used it there yet |
| VS Code Remote (SSH, WSL, Dev Containers) | Not tested |
